## Available shared components (import '../utils/app_theme.dart'; — most screens already have it)

1. EmptyState({required IconData icon, required String title, String? message, Widget? action})
   → replaces any Center(Column(Icon+Text)) empty/no-results placeholder. Keep surrounding Padding/SliverFillRemaining as-is, swap only the inner Center(Column(...)) body.
2. SectionHeader({required String title, String? subtitle, Widget? trailing, IconData? icon, EdgeInsets padding = const EdgeInsets.fromLTRB(24, 36, 24, 12)})
   → replaces section title Rows like Row(Text('X', fontSize: 18-20, w700/w800)). If original had scroll arrows in a trailing Row, pass them via trailing:.
3. MetaPill({required String label, IconData? icon, Color? color}) → small rating/status chips (Container with Row(Icon+Text)).
4. GenreTag({required String label}) → genre chips (rounded pill Containers with short text). Must use named arg: GenreTag(label: x).
5. GradientText(text, {TextStyle? style, Gradient? gradient}) → branded text.
6. DizzyLogo({double size = 32}) → brand mark.
7. DSTypography.textTheme.titleSmall / .headlineSmall / .bodyMedium etc — NEVER DSTypography.h3 (does not exist). Only DSTypography.textTheme.<member> is valid.
8. DS.s0/s1/s2/s3/s4/s5/s6/s8/s10/s12/s16/s20 (4..80), DS.rSm/rMd/rLg/rXl/r2xl/rFull, DS.dFast/dMed/dSlow/dHero, DS.cStd/cIn/cOut — spacing/radius/duration/curve tokens.

## Rules
- ONLY wire components listed above. Do NOT touch AppTheme.primaryColor/bgDark usages (they still work).
- Do NOT restructure layout, do NOT rename methods, do NOT change logic/state — pure visual-component swaps.
- Keep every existing constructor signature of screen classes unchanged.
- After each file: dart format it. After all files: run analyze, check ONLY your files for real errors (list above), fix them.
- Preserve CRLF/LF as-is (editor handles it). Never delete TODOs or comments.
- If a screen has NO matching pattern, leave it and report that.
- Output: list of files wired + patterns replaced + any real errors found. Be terse.
